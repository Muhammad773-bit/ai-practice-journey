# Ai Practice Journey

Practice projects from my AI degree and courses, from Python basics and ML notebooks to FastAPI services and several RAG agents. Each folder is a self-contained exercise.

**Tech:** Python, Jupyter, scikit-learn, FastAPI, LangChain

## What's inside

- `machine-learning/`: intro ML notebook on insurance and tips data
- `python-basics/`: Python fundamentals and error handling
- `fastapi-practice/`: first FastAPI endpoints
- `doc-agent/`: document Q&A agent
- `local-rag-agent/`: RAG with a local model
- `multi-doc-agent/`: index and query many documents
- `multi-model-agent/`: agent that switches between models
- `multidoc-rag/`: LangChain RAG over PDF, DOCX and PPTX
- `multimodal-rag-notebook/`: multimodal RAG in a notebook
- `youtube-langchain/`: LangChain tutorial exercises

## Run it

```bash
cd <project-folder>
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

API keys are read from environment variables. Copy `.env.example` to `.env` and fill in your own keys.
